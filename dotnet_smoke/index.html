Result<T, E> errors

The impedance mismatch. Rust's errors-as-values mapped to C#'s throw-on-failure. Tagged-union DiplomatResult crosses the wire by value; binding checks the tag, throws on Err with the error payload, unwraps on Ok.

Option<T> nullable

Rust's absence type mapped to C# nullables. Two code paths: pointers carry null natively (Option<Box<T>> → bare T*, no extra bytes), value types need a tagged DiplomatOption<T> struct (same machinery as Result, unit error). Caller-side: ?., ??, pattern matching — no exception machinery.

option-walkthrough.html · 2 paths · ✓ shipped

DiplomatWrite writer

Rust can't return String across FFI — its heap is its own. Instead, the caller (C#) provides a writer buffer; Rust appends UTF-8 bytes into it; if the buffer fills, Rust calls back into C# via a function pointer to grow it. Bidirectional FFI in one call. The #1 missing feature for binding real Rust libraries (16/22 picky-rs modules use it).
